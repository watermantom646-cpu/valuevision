# HelpBnk Alpha Step 5 - Pilot with High-Frequency Sellers and Iterate Fast
**Date:** February 21, 2026

## Objective
Run a focused pilot and iterate quickly based on real usage behavior.

## Pilot Setup
1. Target cohort: 20 high-frequency sellers
2. Duration: 14-30 days
3. Focus: real workflows, repeat usage, pricing signal

## Metrics to Track
1. Activation rate
2. Weekly active pilot users
3. Scan success and timeout rates
4. Confidence acceptance vs manual override behavior
5. Paid intent and plan selection

## Feedback Loop
1. Weekly interviews/messages with pilot users
2. Capture top pain points and blockers
3. Prioritize fixes by impact and frequency
4. Ship fast iteration cycles

## Decision Output
At pilot end, produce:
1. Go / refine / pivot recommendation
2. Top 5 product changes
3. Updated 30-day execution plan

## Definition of Done
1. Pilot evidence pack completed
2. Product and pricing decisions made from measured data
3. Next sprint priorities locked
