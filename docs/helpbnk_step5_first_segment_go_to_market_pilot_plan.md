# HelpBnk Step 5 - First-Segment Go-To-Market and Pilot Plan
**Date:** February 21, 2026

## Objective
Run a focused pilot with the first segment, prove usage/value, and produce investor-grade validation evidence.

## First Segment
1. High-frequency eBay sellers (small teams/individuals)
2. Users who make weekly sourcing and pricing decisions

## Pilot Scope
1. Cohort size: 20 users
2. Duration: 14-30 days
3. Product surface: scan -> valuation -> confidence -> action decision

## Acquisition Plan
1. Direct outreach in relevant seller communities
2. Founder-led DMs to targeted users
3. Early-access landing page with clear plan options

## Pilot Metrics
1. Activation: users completing first scan
2. Weekly active pilot users
3. Scan success/timeout rates
4. Pricing-plan interest (Free/Pro/Pro+)
5. Willingness-to-pay and top objections

## Feedback Loop
For each pilot user capture:
1. Primary pain point
2. Most valuable feature
3. What is missing to pay monthly
4. Recommended product/pricing improvements

## 90-Day Milestones Supported
1. Pilot launched and active
2. Reliability targets tracked and improved
3. Early paid conversion signal established
4. Investor update prepared with measured evidence

## Completion Criteria
1. Pilot report completed with quantified outcomes
2. Go/refine/pivot decision made from evidence
3. Next sprint priorities locked for growth phase
