# HelpBnk Step 23 - Run a Private Beta with Active eBay Power Sellers
**Date:** February 21, 2026

## Objective
Validate real-world usefulness and gather proof points before public scale.

## Beta Plan
1. Invite 15-25 active power sellers.
2. Provide onboarding checklist and success criteria.
3. Run live usage for 2-3 weeks.

## What To Observe
1. First-use friction
2. Result clarity and trust
3. Frequency of repeated usage
4. Upgrade trigger moments
5. Most-requested feature improvements

## Proof Targets
1. At least one strong testimonial/case study
2. Early paid conversion signal
3. Clear top improvement themes

## Output
1. Private beta report
2. Case-study snippets/quotes
3. Updated roadmap from beta evidence
