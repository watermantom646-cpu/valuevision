# HelpBnk Step 3 - Package and Pricing Plan (Free, Pro, Pro+)
**Date:** February 21, 2026

## Objective
Set a simple, testable package structure that supports adoption and validates willingness-to-pay quickly.

## Planned Packages
### Free
1. Limited scans per month
2. Basic valuation output
3. Standard confidence indicator

### Pro (GBP 7/month)
1. Higher scan allowance
2. Advanced report details and better history context
3. Saved scan history and faster decision workflow

### Pro+ (GBP 12/month)
1. Highest scan allowance
2. Deeper analytics/profit view
3. Priority features for power users (exports/advanced tools)

## Pricing Hypothesis
1. Free drives top-of-funnel onboarding
2. Pro is the main conversion tier
3. Pro+ captures high-frequency power users

## Month-1 Validation Targets
1. 8-12% of active users show paid conversion intent
2. Clear preference split between Pro and Pro+
3. Objections captured for pricing/feature mismatch

## Experiment Plan
1. Launch landing page with clear plan cards
2. Track clicks on Free/Pro/Pro+
3. Track signups and pilot activation by selected plan
4. Interview users on willingness-to-pay and must-have features

## Decision Rules
1. Strong Pro pull -> keep GBP 7 anchor
2. High Pro+ interest -> expand Pro+ feature depth
3. Weak paid pull -> adjust packaging before wider launch

## Completion Criteria
1. Pricing tiers are understandable to users
2. Early willingness-to-pay signal is measurable
3. Go-forward pricing recommendation documented
