# HelpBnk Step 5 - Pilot with Power Sellers and Validate Pricing/Value
**Date:** February 20, 2026

## Objective
Run a focused pilot with high-frequency sellers to validate product value, pricing acceptance, and usage economics.

## Pilot Cohort
1. Target users: high-frequency eBay sellers (small teams/individuals)
2. Pilot size: 20 users
3. Pilot duration: 14-30 days

## What We Are Testing
1. Product usage frequency
2. Conversion intent from Free -> Pro GBP 7 -> Pro+ GBP 12
3. Confidence in estimates during real buying/listing decisions
4. Per-user data cost vs target ARPU

## Core Metrics
1. Activation: % who complete first scan
2. Weekly active pilot users
3. Scan success and timeout rates
4. Plan interest and conversion signals
5. Top reasons to pay / not pay

## Interview + Feedback Loop
For each pilot user collect:
1. Top job-to-be-done
2. Main pain solved
3. Must-have feature
4. Willingness to pay (GBP 7 / GBP 12 / no)
5. Objections and blockers

## Revenue and Cost Fit Check
1. Estimate data cost per active pilot user
2. Compare to expected revenue per user by selected plan
3. Confirm sustainability threshold before scale

## Decision Framework (Go / Refine / Pivot)
**Go:** strong usage + clear willingness-to-pay + viable unit economics  
**Refine:** strong usage but pricing/friction issues  
**Pivot:** low usage and weak value signal

## Output / Completion Criteria
1. Pilot summary report (usage, conversion intent, top objections)
2. Pricing recommendation (keep GBP 7/12 or adjust)
3. Product decision note: go, refine, or pivot with evidence
