# ValueVision - First User, Problem, and Value Promise

**Date:** February 20, 2026


## 1) First Target User Profile (ICP)

**Primary user:** High-frequency eBay sellers (small teams/individuals) in the UK.  

**Typical profile:**

1. Lists and sells items weekly (often daily)

2. Sources stock from auctions, clearance, marketplaces, and local buys

3. Works across mixed categories (electronics, fashion, tools, collectibles, vehicles/parts)

4. Needs fast buy/no-buy decisions with confidence


**Buying triggers (what makes them pay):**

1. Saves 30-60 minutes/day on comps and pricing checks

2. Reduces bad buys and margin mistakes

3. Gives clear confidence scoring before they commit stock spend

4. Helps them move inventory faster with better pricing


## 2) Priority Starting Categories + Search Terms

**Priority categories for MVP:**

1. Electronics

2. Fashion/luxury accessories

3. Tools

4. Collectibles

5. Vehicles/vehicle parts (as key vertical use case)


**Typical search/decision terms users rely on:**

1. "sold comps"

2. "recent sold price"

3. "market value"

4. "resale value"

5. "profit after fees"

6. "quick flip margin"

7. "authenticity risk"

8. "condition adjustment"


## 3) Top 3 Jobs-To-Be-Done (JTBD) + Outcomes

### JTBD 1: "Help me decide in minutes if this item is worth buying."

**Desired outcome:** Clear buy/no-buy decision with expected margin range.


### JTBD 2: "Help me price accurately so I sell faster without leaving money on the table."

**Desired outcome:** Better list-price confidence and fewer repricing cycles.


### JTBD 3: "Help me avoid risk on authenticity/condition/history before I commit capital."

**Desired outcome:** Fewer loss-making buys and lower refund/dispute exposure.


## 4) One-Line Value Promise + Proof Points

**One-line value promise:**  

ValueVision helps high-frequency sellers scan items and get instant value, risk, and profit clarity so they can buy smarter and sell faster.


**Proof points (MVP-level):**

1. Working scan -> valuation/report flow is live

2. Confidence scoring and category-aware outputs are implemented

3. Reliability checks (health + smoke tests) are in place

4. Early subscription hypothesis is defined (Free, Pro GBP 7, Pro+ GBP 12)


## 5) First Use Cases to Validate

1. In-store/auction sourcing decision (buy/no-buy)

2. Listing price decision for fast turnover vs max margin

3. Risk check before committing cash to mixed-inventory items


## 6) Testable 30-Day Validation Plan

1. Interview 10 high-frequency eBay sellers

2. Onboard first 20 pilot users

3. Track activation, repeated usage, and willingness-to-pay at GBP 7 and GBP 12

4. Capture direct quotes and top "must-have" feature requests


## 7) Success Criteria for This Planning Stage

1. ICP is specific and interviewable

2. Priority categories are clear and executable

3. JTBDs are outcome-focused and measurable

4. Value promise is simple, strong, and testable in pilot
