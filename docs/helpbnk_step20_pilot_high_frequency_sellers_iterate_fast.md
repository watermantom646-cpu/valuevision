# HelpBnk Step 20 - Pilot with High-Frequency Sellers and Iterate Fast
**Date:** February 21, 2026

## Objective
Run a focused pilot and ship fast improvements from real usage.

## Pilot Setup
1. Recruit 20 high-frequency sellers.
2. Run 14-30 day pilot.
3. Define weekly interview/check-in cadence.

## What To Track
1. Activation rate
2. Weekly active users
3. Scan success + timeout rates
4. Trust in estimates/confidence labels
5. Upgrade intent and plan fit

## Iteration Method
1. Capture top pain points each week.
2. Prioritize fixes by frequency and revenue impact.
3. Release improvements in short cycles.

## Output
1. Pilot evidence report
2. Top 5 shipped changes
3. Go/refine/pivot decision for broader beta
